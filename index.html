📷 צילום ותרגום

לקריאת תמונות צריך מפתח Groq (אותו מפתח של ההקלטה השקטה).

תרגום:

💰 מחירים בשקלים (בקירוב)

    טקסט מקורי

    התמונה מוקטנת בטלפון ונשלחת לקריאה בשירות Groq. נשמר רק הטקסט, בהיסטוריה.

    🎧 האזנה לשיחה ותרגום

    להקלטה שקטה צריך פעם אחת מפתח חינמי של Groq.

    משך:

    3:00

    הניחו את הטלפון קרוב לדוברים ולחצו "התחל האזנה".
    כל משפט שיזוהה יתורגם ויופיע כאן.

    ⬇ שמור הקלטה

    בהקלטה שקטה ההקלטה נשלחת בסוף לתמלול בשירות Groq, ובתרגום חי הדיבור עובר דרך Google. שניהם דורשים אינטרנט. בטלפון נשמר רק הטקסט. השאירו את המסך דלוק והאפליקציה פתוחה. לשיחה שאתם חלק ממנה, להדרכה, להכרזות או לשיחה במקום ציבורי. בישראל האזנה לשיחה פרטית של אחרים בלי הסכמה של אחד מהם אסורה (חוק האזנת סתר), ובחו״ל חל החוק המקומי.

    הגדרות

    כדאי להריץ לפני הטיסה, עם השפה של היעד בצד של דובר ב׳.

    קולות הקראה במכשיר
    איך מתקינים קול לשפה חסרה (אנדרואיד)
    1. בהגדרות הטלפון חפשו "המרת טקסט לדיבור" (Text-to-speech).
    2. בחרו במנוע של Google ולחצו על ⚙️ שלידו.
    3. "התקנת נתוני קול" ← בחרו את השפה ← הורידו.
    4. חזרו לכאן ולחצו על כפתור ההשמעה של השפה, כדי לשמוע שהקול נכון.

    אם שומעים קול באנגלית במקום השפה, הקול של השפה עוד לא מותקן.

    זכר ונקבה בתרגום

    עוזר לתרגום ב-Groq לבחור נכון "אתה" או "את", "מוכן" או "מוכנה", ובתאית ครับ או ค่ะ. את הצד השני אפשר להחליף גם בכפתור 👤 ליד "דובר ב׳". התרגום משתמש גם במשפטים האחרונים בשיחה, כדי להבין למה מתכוונים ב"זה", "שם" או "הוא".

    ללא אימייל המכסה החינמית היא כ-5,000 תווים ביום, ועם אימייל כ-50,000. נשמר במכשיר בלבד ונשלח רק לשירות MyMemory.

    פרטיות: הטקסט לתרגום נשלח לשירותי התרגום (Groq כשיש מפתח, MyMemory, ובגיבוי Google ו-Lingva), וזיהוי הדיבור עובר דרך Google. ההיסטוריה, המועדפים והמלון נשמרים רק בטלפון.

    זיהוי דיבור בכפתורי המיקרופון

    Whisper מקליט בשקט (בלי הצליל של הטלפון), מסיים לבד כשמפסיקים לדבר, ומדויק יותר ברומנית ובתאית. לוקח שנייה או שתיים יותר, וצריך מפתח Groq. כפתור "דברו – האפליקציה תזהה מי מדבר" תמיד עובד עם Whisper.

    שרת תרגום אישי (רשות, Microsoft Translator)

    כשמחוברים, התרגום עובר קודם דרך השרת שלך, ואם הוא לא זמין, דרך השירותים הרגילים. כדי להתנתק, מוחקים את הכתובת ולוחצים "שמור ובדוק". מדריך חיבור

    יוצרים מפתח בחינם: console.groq.com ← API Keys ← Create API Key, ומדביקים כאן. המפתח נשמר רק בטלפון הזה, ומי שיש לו את הקישור לא יכול להשתמש בו. כשהתרגום ב-Groq דלוק, הטקסט לתרגום נשלח ל-Groq.

    מפתח בחינם: aistudio.google.com ← Get API key. נשמר רק בטלפון הזה. הטקסט המתורגם נשלח ל-Google; לפי התנאים של Google, בשכבה החינמית התוכן עשוי לשמש לשיפור השירותים שלה. אל תתרגם מידע אישי רגיש כשהאפשרות דלוקה. ההגייה משוערת בלבד.
