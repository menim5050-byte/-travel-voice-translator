# מתורגמן קולי לטיולים (travel-voice-translator)

אפליקציית PWA לנייד, בעברית RTL, למתורגמן קולי דו-כיווני בין **עברית, אנגלית, רומנית, ערבית ותאילנדית**.

## מה יש בפנים
- **שיחה דו-שלבית:** דובר א׳ ודובר ב׳, כפתור "החלף תור" ומעבר תור אוטומטי אחרי תרגום.
- **מצב פנים-אל-פנים:** מסובב את הפאנל של דובר ב׳ ב-180° כדי שהאדם שממול יקרא אותו ישר.
- **זיהוי דיבור והקראה:** המיקרופון מתרגם ומקריא מיד. האודיו נפתח בלחיצה הראשונה (נדרש בנייד), ויש בדיקת שמע בהגדרות שמראה אילו קולות מותקנים.
- **תרגום עם גיבוי:** MyMemory ראשון, ואם נכשל או שהמכסה נגמרה, עוברים ל-Lingva (כמה מופעים לפי הסדר).
- **שיחון אופליין:** 35 משפטים שימושיים בכל חמש השפות, בלי אינטרנט. משפט מהשיחון שמוקלד או נאמר מתורגם אופליין.
- **PWA:** מותקן על מסך הבית, וכל הקבצים נשמרים במטמון.

## מבנה
```
index.html        המסך הראשי
manifest.json     הגדרות התקנה
sw.js             Service Worker (אופליין)
css/styles.css    Tailwind מקומפל (אין תלות ב-CDN)
js/app.js         ממשק ולוגיקה
js/translate.js   MyMemory -> Lingva + מטמון
js/speech.js      זיהוי דיבור והקראה
js/phrasebook.js  השפות והשיחון
icons/            אייקונים
```

## הרצה מקומית
Service Worker ופתיחת מיקרופון דורשים localhost או HTTPS, ולא פתיחת קובץ ישירות.
```bash
cd travel-voice-translator
python3 -m http.server 8000
# פתח בדפדפן: http://localhost:8000
```

## העלאה ל-GitHub Pages
1. צור ב-GitHub מאגר ציבורי חדש בשם `travel-voice-translator` (בלי README, כי כבר יש).
2. מתוך התיקייה:
```bash
git init
git add .
git commit -m "Initial commit: travel voice translator PWA"
git branch -M main
git remote add origin https://github.com/<שם-המשתמש>/travel-voice-translator.git
git push -u origin main
```
3. ב-GitHub: **Settings ← Pages ← Build and deployment ← Source: Deploy from a branch ← Branch: main, תיקייה: / (root) ← Save**.
4. אחרי דקה-שתיים הכתובת תהיה: `https://<שם-המשתמש>.github.io/travel-voice-translator/`

כל הנתיבים בפרויקט יחסיים, ולכן הוא עובד בתת-נתיב של GitHub Pages בלי שינוי.

## התקנה בטלפון
- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקן אפליקציה", או הכפתור בהגדרות.
- **אייפון (Safari):** כפתור השיתוף ← "הוסף למסך הבית".

## מגבלות שחשוב להכיר
- **זיהוי דיבור** משתמש ב-Web Speech API של הדפדפן ודורש אינטרנט. ב-Chrome באנדרואיד הוא עובד בצורה הטובה ביותר. ב-iOS התמיכה קיימת ב-Safari, אך דווח שבאפליקציה שהותקנה על מסך הבית הוא לא תמיד עובד. אם כך, פתח את האתר ב-Safari, או הקלד והשתמש בדיקטציה של המקלדת.
- **הקראה** משתמשת בקולות שמותקנים בטלפון. אם חסר קול לשפה (למשל תאילנדית), התקן אותו בהגדרות הטלפון תחת המרת טקסט לדיבור. בהגדרות האפליקציה מוצג אילו קולות זמינים.
- **MyMemory** חינמי עם מכסה של כ-5,000 תווים ביום ללא זיהוי. הוספת אימייל בהגדרות מעלה אותה לכ-50,000. איכות התרגום טובה למשפטים קצרים ופחות למשפטים ארוכים או מורכבים.
- **Lingva** הוא שירות מתנדבים, ומופעים ציבוריים נופלים מדי פעם. הרשימה נמצאת ב-`LINGVA_INSTANCES` בקובץ `js/translate.js`, וקל להחליף בה.
- **אין לסמוך על התרגום במצבים רפואיים או משפטיים.** השיחון כולל משפטי עזרה, אך מומלץ לאמת אותם מול דובר שפה.

## עדכון גרסה
אחרי שינוי בקבצים, העלה את `VERSION` ב-`sw.js` (למשל `tvt-v2`) כדי שהמכשירים יטעינו את הקבצים החדשים.
