# מתורגמן קולי לטיולים

אפליקציית PWA בעברית (RTL) למתורגמן קולי דו-כיווני בין 22 שפות. נבנתה על העיצוב של גימיני, עם תיקונים ושיפורים ליציבות.

**כתובת האתר:** https://menim5050-byte.github.io/-travel-voice-translator/

## מה היא יודעת
- שיחה בין שני דוברים: מיקרופון, תרגום והקראה, החלפת תור, ומצב פנים-אל-פנים (180°).
- 22 שפות. שיחון אופליין מלא בעברית, אנגלית, רומנית, ערבית, תאילנדית ורוסית.
- "קח אותי למלון": משפט מתורגם עם שם המלון שלך, ופתיחה ב-Google Maps.
- תצוגה מוגדלת במסך מלא להראות לאדם שממול.
- תרגום: MyMemory, ואם נכשל או שהמכסה נגמרה, Lingva (כמה מופעים). תרגומים נשמרים בזיכרון.
- התקנה למסך הבית ועבודה בלי אינטרנט (Service Worker).

## מבנה
```
index.html          המסך
manifest.json, sw.js
css/input.css       מקור העיצוב, css/styles.css הקובץ המקומפל
js/app.js           הממשק והלוגיקה
js/languages.js     22 השפות וקודי השירותים
js/phrasebook.js    השיחון האופליין
js/translate.js     MyMemory -> Lingva + זיכרון
js/speech.js        זיהוי דיבור והקראה
tests/e2e.py        בדיקות דפדפן
```

## עבודה על הקוד
```bash
npm install
npm run build:css   # אחרי שינוי בעיצוב או בכיתובי Tailwind
npm run serve       # http://localhost:8766
npm test            # דורש playwright ו-Chrome
```
אחרי שינוי בקבצים, העלה את `VERSION` ב-`sw.js` (למשל `tvt-v4`).

## מגבלות
- זיהוי דיבור ב-Web Speech API, דורש אינטרנט. עובד הכי טוב ב-Chrome באנדרואיד. באייפון באפליקציה שהותקנה עלול לא לעבוד.
- ההקראה משתמשת בקולות של הטלפון. אם חסר קול לשפה, צריך להתקין אותו (הגדרות ← המרת טקסט לדיבור). בהגדרות באפליקציה מוצג אילו קולות קיימים.
- MyMemory חינמי: כ-5,000 תווים ביום, וכ-50,000 עם אימייל בהגדרות. Lingva מתנדבים ויכול ליפול. הרשימה ב-`LINGVA_INSTANCES` בקובץ `js/translate.js`.
- תרגום מכונה. במצבים רפואיים או משפטיים כדאי לאמת מול דובר שפה.
