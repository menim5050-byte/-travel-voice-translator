# מתורגמן קולי לטיולים

אפליקציית PWA בעברית (RTL) למתורגמן קולי דו-כיווני בין 22 שפות. נבנתה על העיצוב של גימיני, עם תיקונים ושיפורים ליציבות.

**כתובת האתר:** https://menim5050-byte.github.io/-travel-voice-translator/

## מה היא יודעת
- שיחה בין שני דוברים: מיקרופון, תרגום והקראה, החלפת תור.
- מצב פנים-אל-פנים: הצד של דובר ב׳ הפוך ופונה אליו, בשפה שלו, וכל אחד רואה בצד שלו את התרגום שמיועד לו.
- 22 שפות. שיחון אופליין בעברית, אנגלית, רומנית, ערבית, תאילנדית ורוסית (68 משפטים: בסיסי, מונית, כסף, מלון, אוכל, בריאות ובית מרקחת, רכב וקטנוע).
- "קח אותי למלון": משפט מתורגם עם שם המלון, שנפתח מיד בתצוגה גדולה לנהג. גם פתיחה ב-Google Maps.
- תצוגה מוגדלת במסך מלא. נגללת בטקסט ארוך, ונסגרת ב"חזור" של הטלפון.
- היסטוריה שנשמרת בטלפון, ומועדפים ⭐ שעובדים גם בלי אינטרנט.
- "בדוק משמעות": מתרגם את התוצאה חזרה לשפה שלך. גם העתקה ושיתוף.
- המסך נשאר דולק בזמן שיחה.
- 🎧 מצב האזנה לשיחה שמסביב (1 עד 10 דקות), בשתי דרכים:
  - 🔇 הקלטה שקטה (ברירת מחדל): מקליט בלי צלילים ובלי עצירות, ובסוף שולח פעם אחת לתמלול ב-Whisper של Groq (זיהוי שפה אוטומטי), ומתרגם לעברית עם זמנים. דורש מפתח Groq חינמי, שנשמר רק בטלפון (הגדרות). אם השליחה נכשלת, אפשר לנסות שוב או לשמור את ההקלטה.
  - ⚡ תרגום חי: משפט-משפט עם זיהוי הדיבור של הטלפון (באנדרואיד יש צליל בכל התחלה).
  - בסוף: העתקה, שיתוף, והשיחה נשמרת בהיסטוריה.
- 📷 צלם ותרגם: צילום או תמונה מהגלריה (שלט, תפריט, צילום מסך של הודעה). התמונה מוקטנת ונשלחת למודל הראייה של Groq (נבחר אוטומטית מבין המודלים הזמינים, כרגע qwen/qwen3.8-27b), שקורא ומתרגם לעברית. יש גם תרגום חלופי לבדיקה. אותו מפתח Groq.
- 💰 מחירים בשקלים: מחירים שזוהו בצילום מוצגים גם בשקלים, לפי שער יומי (ExchangeRate-API, גיבוי Frankfurter), שנשמר בטלפון ל-12 שעות.
- ↗ "שתף אל המתורגמן": טקסט או תמונה מאפליקציה אחרת (למשל וואטסאפ) נפתחים במתורגמן. טקסט בשפה זרה מזוהה לבד ומתורגם לעברית, ותמונה עוברת לצילום ותרגום. עובד רק כשהאפליקציה מותקנת כאפליקציה (share_target).
- זיהוי סוף משפט: האפליקציה מסיימת לבד אחרי 1.8 שניות של שקט, בכל השפות (גם כשזיהוי הדיבור של הטלפון לא מסיים, כמו ברומנית).
- 🎙️ זיהוי דיבור עם Whisper בשיחה (הגדרות ← "זיהוי דיבור בכפתורי המיקרופון"): כפתורי המיקרופון מקליטים בשקט, בלי צליל, מסיימים לבד אחרי כ-1.8 שניות של שקט (רעש קצר אחרי הלחיצה לא נחשב דיבור, והפסקה קצרה באמצע משפט לא חותכת), ושולחים ל-Whisper בשפה של הדובר. אותו מפתח Groq.
  - המודל בשיחה הוא `whisper-large-v3` (המדויק יותר לפי Groq), ו-`whisper-large-v3-turbo` כגיבוי. הקלטות ארוכות (מצב האזנה) נשארות על turbo.
  - קטעים שנראים כמו רעש שהומצא כטקסט (למשל "תודה שצפיתם") מושמטים ולא מתורגמים. הסינון לפי הנתונים ש-Groq מחזיר לכל קטע (`no_speech_prob`, `avg_logprob`, `compression_ratio`), עם ברירות המחדל של Whisper.
  - אחרי כל הקלטה מופיעה רצועה קטנה מתחת לכפתור "דברו": אורך, עוצמה מקסימלית, מודל ושפה, וכפתור "▶ שמע את ההקלטה". כך רואים אם הבעיה בהקלטה עצמה (חלשה, חתוכה, מעוותת) או בזיהוי.
- 🎙️ "דברו – האפליקציה תזהה מי מדבר": לחיצה אחת, מדברים בכל אחת משתי השפות, והאפליקציה מזהה את השפה ואת הדובר לבד ומתרגמת לצד השני. כתב חד-משמעי (עברית, ערבית, תאית, רוסית) מכריע גם אם Whisper טעה בשפה. שפה שלישית מתורגמת לשפה של דובר א׳. "רציף": אחרי התרגום וההקראה מתחיל להאזין שוב לבד (נעצר בלחיצה, ביציאה מהאפליקציה, או אחרי 3 פעמים בלי דיבור).
- התקנה למסך הבית. נפתחת מהטלפון מיד, גם בלי אינטרנט ובאינטרנט חלש.
- 🧳 בדיקת מוכנות לטיול (בראש ההגדרות): בודקת אינטרנט, פתיחה בלי רשת, התקנה, מיקרופון, קולות הקראה, שיחון לשפת היעד, מפתח Groq, Whisper, צילום, ותרגום אמיתי של משפט דרך Groq, MyMemory ו-Google. ✓ תקין, ⚠ הערה, ✗ צריך לתקן.

## איך התרגום עובד
0. שרת אישי (רשות, **מוסתר** בהגדרות כברירת מחדל; מוצג רק למי שכבר מחובר, או בכתובת עם `?advanced=1`): Microsoft Translator דרך שרת ב-Cloudflare. מדריך: [server/README.md](server/README.md). אם השרת לא מחובר או לא זמין, ממשיכים לשלבים הבאים.
1. שיחון מובנה (בלי רשת).
2. זיכרון תרגומים בטלפון (300 אחרונים).
3. Groq, אם יש מפתח Groq (דלוק כברירת מחדל, אפשר לכבות בהגדרות): מודל שפה (openai/gpt-oss-120b, ואם הוא עמוס gpt-oss-20b) שמתרגם בצורה טבעית. בלי שרת ובלי הרשמה נוספת. בחינם עד כ-1,000 תרגומים ביום לכל מודל. מפתח לא תקין, עומס או תשובה שאינה תרגום: עוברים לבד לשלב הבא.
   - זכר ונקבה: בהגדרות (או בכפתור 👤 ליד "דובר ב׳") בוחרים אם אתה ואם הצד השני גבר או אישה, והתרגום מתאים "אתה/את", "מוכן/מוכנה", ובתאית ครับ/ค่ะ.
   - הקשר: עד 3 המשפטים האחרונים בשיחה (מ-15 הדקות האחרונות) נשלחים כרקע, כדי לתרגם נכון "זה", "שם", "הוא".
   - הקלטה ארוכה במצב האזנה מתורגמת בבקשה אחת (או בכמה בקשות גדולות), כך שהמודל רואה את כל השיחה. אם התשובה לא תקינה, מתרגמים קטע-קטע.
4. MyMemory. טקסט ארוך מחולק לחלקים של עד 450 בתים. כשהמכסה היומית נגמרת, MyMemory מושהה עד שעה.
5. גיבויים במקביל: Google (נקודת קצה לא רשמית, חינמית, עלולה להיחסם בלי הודעה) ושרתי Lingva של מתנדבים (בבדיקה ב-19.11.2026 לא עבדו).
6. תקרה של 12 שניות לכל התרגום, עם הודעה ברורה.

## מבנה
```
index.html            המסך
manifest.json, sw.js  התקנה ועבודה בלי אינטרנט
css/input.css         מקור העיצוב, css/styles.css הקובץ המקומפל
js/app.js             הממשק והלוגיקה
js/languages.js       22 השפות, קודי השירותים ומשפט דוגמה לכל שפה
js/phrasebook.js      השיחון האופליין
js/translate.js       שרת אישי -> שיחון -> זיכרון -> Groq -> MyMemory -> גיבויים
js/speech.js          זיהוי דיבור והקראה
js/ui-strings.js      טקסטים לצד של דובר ב׳ במצב פנים-אל-פנים
js/recorder.js        הקלטה שקטה (MediaRecorder), מד עוצמה וזיהוי סוף משפט
js/transcribe.js      תמלול ב-Groq Whisper (מפתח אישי בטלפון), בחירת מודל וסינון קטעים חשודים
js/vision.js          קריאה ותרגום של תמונה (Groq, בחירת מודל אוטומטית)
js/currency.js        שערי מטבע והמרה לשקלים
tools/stamp-sw.py     חותמת גרסה אוטומטית
server/worker.js      השרת האישי (Cloudflare Worker): קוד גישה + Microsoft Translator
tests/                בדיקות דפדפן
```

## עבודה על הקוד
```bash
npm install
npm run build:css           # אחרי שינוי בעיצוב או בכיתובי Tailwind
python3 tools/stamp-sw.py   # חובה אחרי כל שינוי בקבצים, לפני העלאה
npm run serve               # http://localhost:8766
node tests/vad_test.mjs && node tests/worker_test.mjs && node tests/transcribe_test.mjs   # בדיקות יחידה
python3 tests/e2e.py && python3 tests/e2e_more.py   # עם השרת פועל
python3 tests/e2e_update.py # בדיקת עדכון גרסה (מפעיל שרת משלו)
```
`tools/stamp-sw.py` מחשב את הגרסה מתוכן הקבצים וכותב אותה ב-`sw.js` ובכתובות `?v=` שב-`index.html`. כך הטלפון תמיד מקבל גרסה שלמה אחת, ולעולם לא מערבב קובץ ישן עם חדש. הבדיקות נכשלות אם שכחו להריץ אותו.

## עדכון בטלפון
גרסה חדשה יורדת ברקע בשלמותה ונכנסת לפעולה מיד אם לא באמצע שיחה. אם באמצע שיחה, מופיעה הודעה "גרסה חדשה מוכנה" עם כפתור "רענן עכשיו".

## מגבלות
- זיהוי דיבור ב-Web Speech API דורש אינטרנט. עובד באנדרואיד (Chrome, Brave).
- ההקראה משתמשת בקולות של הטלפון. בהגדרות יש כפתור השמעה לכל שפה, והסבר איך מתקינים קול חסר.
- MyMemory חינמי: כ-5,000 תווים ביום לפי חיבור האינטרנט, וכ-50,000 עם אימייל בהגדרות.
- פרטיות: הטקסט לתרגום נשלח לשירותי התרגום, וזיהוי הדיבור עובר דרך Google. היסטוריה, מועדפים, מלון ואימייל נשמרים רק בטלפון.
- תרגום מכונה. במצבים רפואיים או משפטיים כדאי לאמת מול דובר שפה. את המשפטים בתאית כדאי שדובר תאית יעבור עליהם.
