# חיבור שרת התרגום האישי (Cloudflare + Microsoft)

המדריך מתאים למחשב, אבל אפשר לעשות אותו גם בטלפון. כל ההרשמות חינמיות, וזה לוקח בערך חצי שעה, פעם אחת.

**מה מקבלים:** התרגום עובר דרך Microsoft Translator, שירות רשמי ויציב. המפתח שמור בשרת שלך, ורק מי שיש לו את קוד הגישה שלך יכול להשתמש בו. אם השרת לא זמין, האפליקציה חוזרת לבד לשירותים הרגילים.

> ⚠️ את המפתחות ואת קוד הגישה לא שולחים לאף אחד, גם לא בצ׳אט.

---

## חלק א׳: שירות התרגום ב-Microsoft Azure

1. נכנסים ל-**portal.azure.com** ומתחברים עם חשבון Microsoft. אם אין חשבון Azure, נרשמים.
   - בהרשמה ייתכן שיבקשו טלפון וכרטיס אשראי, לאימות זהות בלבד.
2. למעלה בוחרים **Create a resource**, מחפשים **Translator**, בוחרים בו ולוחצים **Create**.
3. ממלאים את הטופס:
   - **Subscription:** משאירים את מה שמופיע.
   - **Resource group:** לוחצים **Create new** וכותבים `translator`.
   - **Region:** בוחרים **West Europe**.
   - **Name:** שם ייחודי, למשל `meni-translator-2026`.
   - **Pricing tier:** בוחרים **F0 (Free)**. זה הסעיף החשוב.
     - בתוכנית החינמית יש 2 מיליון תווים בחודש. כשהם נגמרים, השירות מפסיק עד החודש הבא, והאפליקציה עוברת לגיבוי.
4. לוחצים **Review + create**, ואז **Create**. מחכים שיופיע **Go to resource** ולוחצים עליו.
5. בתפריט של השירות בוחרים **Keys and Endpoint** ושומרים בצד שני פרטים:
   - **KEY 1:** רצף ארוך של אותיות ומספרים.
   - **Location/Region:** למשל `westeurope`.

---

## חלק ב׳: השרת ב-Cloudflare

1. נכנסים ל-**dash.cloudflare.com** ונרשמים עם אימייל וסיסמה. זה חינם, בלי כרטיס אשראי.
2. בתפריט בוחרים **Workers & Pages** (או **Compute**), ואז **Create**, ואז **Create Worker**.
   - נותנים שם, למשל `tvt-translator`, ולוחצים **Deploy**.
3. לוחצים **Edit code**:
   - מוחקים את כל הקוד שמופיע.
   - מדביקים במקומו את כל התוכן של הקובץ:
     https://raw.githubusercontent.com/menim5050-byte/-travel-voice-translator/main/server/worker.js
     פותחים את הקישור, מסמנים הכול (Ctrl+A), מעתיקים ומדביקים.
   - לוחצים **Deploy**.
4. חוזרים לעמוד של ה-Worker ונכנסים ל-**Settings**, ואז ל-**Variables and Secrets**. מוסיפים שלושה משתנים, כולם מסוג **Secret**:

   | שם (Variable name) | ערך |
   |---|---|
   | `ACCESS_CODE` | קוד גישה שאתה בוחר: לפחות 8 תווים, אותיות ומספרים, ולא סיסמה שאתה משתמש בה במקום אחר |
   | `AZURE_KEY` | ה-KEY 1 מחלק א׳ |
   | `AZURE_REGION` | ה-Region מחלק א׳, למשל `westeurope` |

   שומרים ולוחצים **Deploy**, אם מופיע.
5. מעתיקים את הכתובת של ה-Worker. היא נראית כך: `https://tvt-translator.xxxx.workers.dev`
6. **בדיקה מהירה:** פותחים בדפדפן את הכתובת עם `/health` בסוף. אם מופיע `{"ok":false,"error":"bad-code"}`, השרת חי. השגיאה תקינה, כי הדפדפן לא שלח קוד גישה.

---

## חלק ג׳: חיבור בטלפון

1. פותחים את המתורגמן ונכנסים ל-**⚙️ הגדרות**, לחלק **"שרת תרגום אישי"**.
2. מדביקים את כתובת ה-Worker ואת קוד הגישה, ולוחצים **שמור ובדוק**.
3. אם מופיע **"✓ מחובר"**, זהו. מעכשיו התרגום עובר דרך השרת שלך.

**אם יש שגיאה:**

| הודעה | מה לעשות |
|---|---|
| קוד הגישה לא נכון | הקוד בטלפון ו-`ACCESS_CODE` בשרת חייבים להיות זהים, כולל אותיות גדולות וקטנות |
| לא הוגדר מפתח Azure | בדוק שהמשתנה נקרא בדיוק `AZURE_KEY`, ולחץ **Deploy** אחרי השמירה |
| מפתח Azure לא תקין | העתק שוב את KEY 1, ובדוק ש-`AZURE_REGION` תואם לאזור שבחרת |
| אין חיבור לשרת | בדוק את הכתובת (מתחילה ב-`https://` ומסתיימת ב-`workers.dev`) ואת האינטרנט |

**התנתקות:** בהגדרות מוחקים את הכתובת ולוחצים **שמור ובדוק**.

**אם הקוד דלף:** משנים את `ACCESS_CODE` ב-Cloudflare, ומעדכנים אותו בטלפון.

**אם מפתח Azure דלף:** ב-Azure, ב-**Keys and Endpoint**, לוחצים **Regenerate Key 1**, ומעדכנים את `AZURE_KEY` ב-Cloudflare.
